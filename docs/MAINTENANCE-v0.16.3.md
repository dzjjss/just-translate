# v0.16.3：后台重连、预检复用与状态基线

同一工作树继续修改，未提交或推送。发布包根目录包含 manifest.json，版本统一 0.16.3。旧报告保留在 MAINTENANCE-v0.16.2.md。

## 行为

| 场景 | 当前行为 |
| --- | --- |
| 后台重启，原页面继续 | 收到未执行的 session-expired 且后台 epoch 变化时，共享一次显式登记；该请求最多重发一次 |
| 同代次取消、登记期间停止 | 不复活旧任务；迟到登记被中止 |
| 通道断开 | 执行和计费状态未知，不自动重发可能已执行的请求 |
| 配置、权限变化 | 重连重新检查语义版本和权限，不偷偷换配置继续 |
| 权限检查迟到 | 比较确切登记对象，旧任务不能取消同 ID 的新登记 |
| 页面刷新 | 预检绑定完整正文身份、摘要、页面元数据与实际翻译语义版本；同画像可复用同一整页翻译缓存 |
| 连续强制预检 | 最后发起者拥有缓存写入资格；旧结果不能覆盖新画像，刷新失败保留上次有效画像 |
| 清空缓存 | 同时清理译文和画像；清空前发出的预检不能迟到写回 |

重连集中在 connection.js，main 调用 requestSession。没有持久化 AbortController、重试队列或另一份完成状态。workerEpoch 是每次后台启动生成的不可变标识，不是活动开关。

画像复用现有 cache.js 存储、清除代次和写入队列；每条最多 16,000 字符，最多 128 条，有效期七天。记录包含画像、创建时间和刷新期间的请求标识，不保存摘要正文。关闭 useCache 不读写画像；显式重新读取语境绕过旧画像。正常画像完成后等待缓存落盘再回答。

PROMPT_VERSION 保持 13，翻译指令未改。v0.16.2 没有持久画像，升级后的首次预检仍可能产生不同画像，不能保证吃到升级前的整页缓存。

最终 Node/V8 覆盖率：行 90.39%、分支 77.78%、函数 83.16%。包含新增线程测试，不将其冒充真实浏览器覆盖。

新增测试真正销毁并重建独立 Node Worker，重新加载 service-worker.js 及全部后台模块；仅保留模拟 storage 内容。此测试验证模块内存丢失后的代码行为，不能替代 Chrome 自己的生命周期调度。

| 首次页面会话 | 1 | 1 |

翻译命中时 translateRequestCount=0、wholePageCacheHit=true；画像命中时 reused=true、cacheSource=background-cache、usage=null，没有新增模型观测。

## 真实浏览器验收：未完成

环境没有 Chrome/Chromium 或可用浏览器控制实例。已尝试 Playwright 安装 Chrome for Testing，下载连续超时、安装失败。没有把真实五分钟挂起、页面冻结和权限 UI 操作计作通过。

包内提供 test/fixtures/lifecycle.html。项目目录运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/test/fixtures/lifecycle.html`。加载当前扩展，选择英语以外的目标语言。

1. **空闲后的新段落。** 翻完基础页，关闭扩展面板与 worker DevTools，切走五分钟。回来点击“加入一段新正文”。已有译文应保留，新段落应翻译；若后台确已回收，日志应出现 session-reconnected。没有这个事件不能证明曾发生回收。
2. **翻译途中切走。** 刷新测试页，追加长页面内容，开始翻译后切走五分钟。回来核对进度和诊断。提前完成只能记为正常后台完成，不能当作在途回收验证。
3. **刷新缓存。** 基础页开启缓存与整页优先，普通翻译后刷新，再普通翻译。比较预检 hash、reused、translateRequestCount、wholePageCacheHit。不要用故意绕过缓存的“重翻”按钮测命中。
4. **取消边界。** 翻译途中主动停止，等待后台空闲后返回，旧任务不应自行继续；手动开始应建立新页面会话。

worker DevTools 会保持后台活跃；扩展面板查询也可能影响空闲条件，等待期间都应关闭。线程夹具的译文缓存先明确落盘；真实进程若在三秒批量写入前被强杀，最近缓存仍可能丢失。

## 译质与成本基线

Apple 文档新译文尚未实际采样。本轮无可用的已配置供应商会话，没有用测试桩译文充当质量基线。

真实采样应保存源页面、语言方向、扩展和模型版本、预检画像及 hash、译文 Markdown、一次性诊断。先显式读取新语境，再绕过翻译缓存做一次整页采样，随后普通刷新验证复用。译质和重复访问成本是独立验收项；没有真实访问分布，不报告全站缓存命中率改善百分比。
