# v0.16.2：执行边界与代码卫生

本轮从已交付的 v0.16.1 继续修改，保留既有工作树。没有提交或推送 Git；发布包根目录直接包含 manifest.json，不附加内部修复标签。

## 已完成

| 范围 | v0.16.2 行为 |
| --- | --- |
| 后台启动 | 消息与快捷键等待同一个启动任务；启动失败返回明确错误，不留下无人处理的 rejection |
| 会话失效 | 已取消或被后台回收的会话不能由翻译请求重建；页面停止剩余任务并提示重新开始 |
| 权限撤回 | 撤回事件中止相关会话；每批发请求前再次检查权限，防止只在登记时检查 |
| 标签页隔离 | 导航、关闭、停止只取消对应标签页；停止网络工作不依赖内容脚本能够回答 |
| 接口协议 | Anthropic 损坏内容结构按可恢复错误处理，保留 usage；普通 HTTP 400 不冒充 JSON 协议降级；Retry-After 支持秒数和 HTTP 日期 |
| DOM 删除与属性变化 | 同时观察新增、删除、文字与指定属性；已删除、隐藏或改写的单元退出当前页面计数，旧译文清除 |
| 迟到结果 | 提交前按当前 DOM 核对来源，即使响应早于 400ms 防抖，也不能写入过期译文 |
| 预检期间改文 | 按当前正文重新核对画像身份；旧画像作废，最多补一次预检；正文继续变化则用当前正文继续，不无限预检 |
| 仅译文模式 | 同步读取布局时暂时恢复扩展隐藏的原文，读取后立即还原；自身隐藏不会被当成网页删除 |
| 结果合同 | 空条目、重复 ID、非数组失败字段及异常统计值都在消息边界处理，保留其他有效条目 |
| 错误显示 | 主动状态推送与查询共用快照；错误消息来自会话已有记录，不被后续空消息覆盖 |

仍保留 v0.16.1 的统一设置写入、会话配置快照、attempt 提交校验、整页缓存全有或全无、最多 9 次 HTTP 尝试及 120 秒取消信号、日志按已复制序号清除等约束。

## 实际减少的状态与重复逻辑

- 术语预期总数、对齐总数从各类别计数求和。
- 每个术语的 occurrenceCount 从译法次数求和。
- 先例查询总数从命中、未命中、冲突三类结果求和。
- 先例结果总数从匹配、分歧、未对齐三类结果求和。
- MutationObserver 不再额外维护 running 标志；观察资源和待执行计时器由 start/stop 管理。
- 主动推送与查询状态共用 pageStateSnapshot，避免两份字段清单逐渐分叉。
- popup/view-model.js 只计算显示数据，不持有状态、不访问 DOM、不发送消息、不写设置。
- 缓存身份与 prompt 序列化共用规范化的页面上下文字段。
- YAML 解析按行解析、区段选择、区段写入分工；多行原则不会再落入数组写入路径。空解析结果不共享可变集合。

没有增加“正文已脏”“画像已脏”等长期标志。当前 DOM 快照只在扫描、提交或预检核对时生成，不消耗单元 ID，不保存另一份跨请求正文副本。提交前增加一次同步扫描有成本；尚未对大型动态站点做浏览器性能基准。

## 剩余验证与边界

1. **真实 Chrome MV3 生命周期实测。** 当前执行环境没有可用的 Chrome 实例。本轮模拟了后台事件与失效会话，但没有实际杀死浏览器 worker、等待长时间后台挂起或在真实权限 UI 中撤回权限。此项仍未完成。
2. **真实供应商连通性与译质。** DeepSeek、Google、DeepLX、Anthropic 的 live API 未在本轮调用。协议 mock 与执行测试不能保证实时服务可用、译名正确或上下文改善。
3. **大型动态站点性能。** DOM 核对解决了正确性问题，但同步布局读取的耗时与开销尚需浏览器实测。没有声称翻译速度提升。
4. **覆盖仍非完整。** 消息路由、调试工具与兼容性分支仍有未覆盖路径；复杂度达标不替代这些验证。
5. **既有规模边界。** 单次源文硬上限 12,000 字符，system+user 硬上限 48,000 字符；不是精确 tokenizer 保证。超大单元明确失败，未实现自动切句重组。不断变化的页面没有保证整页始终共享同一次语境。

## 本地浏览器验收路径

使用一个固定的开发者模式加载目录，备份后更新文件并重新加载扩展，避免同时运行历史副本。设置、Key 与缓存检查都使用该目录对应的同一个扩展。

建议分别验证：

- 翻译进行中关闭或导航标签页：后续网络请求停止，另一个翻译中的标签页不受影响。
- 让后台 worker 停止后在原页继续操作：出现重新开始提示；重新开始建立新会话。
- 请求进行中撤回 API 域名权限：在途请求中止，后续批次不发送；重新授权后可重新开始。
- 仅译文模式下增删正文、隐藏再恢复段落：原文与译文不丢失，计数与当前页面一致。
- 翻译时断网、恢复网络后手动重试：错误可见，已成功段落保留，无无限恢复请求。

这些是待执行的真实浏览器验收步骤，不计入已通过的 274 个用例。
